# HTA-FileManager

Файловый менеджер для Windows в одном файле. Скачиваешь `file-manager.hta`, дважды кликаешь, он работает. Ставить ничего не надо, Python и Node тоже не нужны.

Сделал для себя: в проводнике мне не хватало нормальных вкладок, а тащить ради этого целый Total Commander не хотелось.

## Как запустить

1. Скачай `file-manager.hta`
2. Открой двойным кликом

Нужна Windows 10 или 11. HTA встроен в систему, так что больше ничего не требуется.

Если антивирус заругался, это нормально: он не любит любые `.hta`, потому что их часто используют во вредоносах. Файл открытый, можно прочитать код и убедиться, что там ничего лишнего.

## Что умеет

- Вкладки. Каждая помнит свою историю, назад и вперёд работают отдельно.
- Копировать, вырезать, вставить, удалить (в корзину), переименовать, создать папку или txt-файл. Копирование и удаление идут через стандартные диалоги Windows, так что прогресс и вопросы про замену файлов выглядят привычно.
- Правая кнопка мыши открывает контекстное меню.
- Сортировка по любому столбцу, клик по заголовку.
- Поиск по текущей папке. Вложенные папки он не смотрит.
- Избранные папки слева. Список лежит в `%APPDATA%\HTA-FileManager.ini`, туда же сохраняется тема.
- Тёмная тема, переключается кнопкой справа сверху.
- Двойной клик по `.zip`, `.tar`, `.gz`, `.tgz`, `.7z` или `.rar` распаковывает архив в `%TEMP%\HTA-FM` и открывает эту папку. Распаковкой занимается встроенный в Windows `tar`, поэтому `7z` и `rar` пойдут не на каждой сборке.

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| `Ctrl+T` / `Ctrl+W` | новая / закрыть вкладку |
| `Alt+←` / `Alt+→` | назад / вперёд |
| `Backspace` или `Alt+↑` | на уровень вверх |
| `F5` | обновить |
| `F2` | переименовать |
| `Del` | удалить в корзину |
| `Shift+Del` | удалить совсем |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | копировать / вырезать / вставить |
| `Ctrl+A` | выделить всё |
| `Ctrl+F` | поиск |
| `Ctrl+L` | перейти в строку пути |
| `Ctrl+D` | добавить папку в избранное |
| `Ctrl+Shift+N` | новая папка |
| `Esc` | закрыть меню или поиск, а если ничего нет, то само окно |

## Что не очень

- Только Windows. HTA придумала Microsoft, больше он нигде не запустится.
- Архив не листается как в WinRAR, он именно распаковывается. После перезагрузки Windows может почистить `%TEMP%`.
- В папках, где десятки тысяч файлов, список, скорее всего, будет открываться медленно. Я это не проверял, но он рисует всё разом.
- Перетаскивать файлы мышкой между вкладками нельзя.
- Интерфейс только на русском. Если нужен другой язык, строки в `file-manager.hta` легко найти и перевести.

## Технологии

HTA, JScript и ActiveX (`Scripting.FileSystemObject`, `WScript.Shell`, `Shell.Application`). Всё лежит в одном файле.
